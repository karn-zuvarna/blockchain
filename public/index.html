ICOToken Admin
Actions
Each action requires Trezor confirmation before the transaction is broadcast.
⬅

Select an action from the sidebar

🚀 Deploy contract

Deploys a new ICOToken to the selected network. You will be prompted to confirm on your Trezor.

⬆︎ Mint tokens

Mints new tokens to any address. Requires MINTER_ROLE. Amount is in whole tokens (18 decimals applied automatically).

🔥 Burn tokens

Burns tokens held by the token contract address itself. Requires BURNABLE_ROLE. Amount is in whole tokens.
